I built a personal portfolio website as my AI Fluency Track final project.

The goal was not just to make another static profile page. I wanted one professional home base that brings together my AI/ML positioning, experience, skills, resume, contact path, and final project evidence in a way that is easy for a recruiter, mentor, or collaborator to inspect.

The live site introduces me as K Praveen Kumar, an ML Engineer Intern at FlyRank AI and BTech Artificial Intelligence student at Marwadi University. It includes sections for About, Experience, Capabilities, Credentials, Find Me, and a Capstone / Featured Project area for final submission evidence.

The biggest change during development was moving from "portfolio as poster" to "portfolio as a small working product." I added exactly one dynamic feature: a working contact form using Netlify Forms. A visitor can send a real message, and the submission is handled by Netlify's backend. I also wrote a plain-language explainer so I can describe what the backend does and how the data flows from the browser to Netlify.

One design decision I made was to keep the project lightweight. The site uses plain HTML, CSS, and small JavaScript files instead of a large frontend framework. That made it faster to understand, easier to maintain, and easier to explain in a live demo.

One real limitation is that the project does not yet have complete V1/V2 evaluation numbers. I have mobile audit notes, form-hardening notes, and launch-status evidence, but I still need to complete a reproducible evaluation table with real before/after results. I documented that gap instead of inventing metrics.

What I learned most is that credibility comes from proof. A clean design helps, but the stronger signal is whether the project has a working feature, honest limitations, clear documentation, and evidence that someone else can inspect.

Next, I want to add a stronger case-study section with real project write-ups and complete the V1/V2 evaluation with measured evidence.
